# Publication checklist

- [ ] Confirm the Cisco/Splunk BOTS event rules allow sharing challenge answers and question panels after the event.
- [ ] Inspect every image for private session cookies, access tokens, credentials, personal information and instance URLs. Remove anything sensitive.
- [ ] Keep only confirmed results; do not describe guesses as findings.
- [ ] If an image seems too small to read, use the original higher-resolution screenshot instead of upscaling.
- [ ] On GitHub, create a public or private repository named `splunk-bots-scenario1-investigation` and upload `README.md` along with the `screenshots` folder.
- [ ] Review the rendered README in GitHub before sharing it on LinkedIn or a resume.

## Screenshot selection

The original PDF had multiple embedded screenshots. This bundle deliberately excludes screenshots showing raw JSESSIONID cookie values, and avoids the live-search screenshot with session data. Screenshots showing questions/answers should only be published if permitted by the event.
